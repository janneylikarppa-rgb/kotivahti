# Home Maintenance Hub

Vinkki Lovablelle

Liitä prototyyppitiedosto (kotiluotsi.html) Lovablen visuaaliseksi referenssiksi. Se näyttää tarkalleen miltä jokainen sivu näyttää, mitä kenttiä lomakkeissa on ja miten navigaatio toimii. Pyydä Lovablea rakentamaan sama toiminnallisuus Supabase-backendillä.

Tärkeä Lovable-prompti

Käytä tätä aloituspromptiä Lovablessa:
"Rakenna omakotitaloasujien huoltokirja-sovellus suomeksi. Käytä Supabase-tietokantaa käyttäjien datan tallentamiseen. Tietokantarakenne on dokumentissa. Visuaalisena referenssinä käytän liittämääni HTML-prototyyppiä. Aloita kirjautumisella ja dashboard-sivulla jossa on talon tiedot, huoltohistoria ja kulujenseuranta."

This project was built with [Lovable](https://lovable.dev).
